然后，软件工程和 devops 工程的主要区别在于，devops 工程主要围绕 git 去做，然后呢，重点主要在这个代码环节主要在这个提交，就是 commit 啊，push 这些同步活动

我们在 build 和 test 环节再去做以下检查：

1. build 环节：
(a) 项目里面这个库的配置有没有按照我们的配置去做；
(b) 各种编译的配置有没有按照这个配置去做，等等。

2. test 环节：
(a) 看有没有测试配置；
(b) 测试有没有通过数据，等等（比如通过给他 action，或者通过其他方式）。

因为从目前的实测来看，如果直接集成这些功能，造成的直接后果就是完全不能用，所以不如直接检查结果。而且本地检查效果不好，必须要在云端上看，所以它更多的是带有很强的审计功能。
