一句话：工作记忆是当前任务的“操作台”，情景记忆是过去经历的“档案库”；两者通过“检索→使用→反思→写入”形成闭环。

1. 核心区别

维度 工作记忆 情景记忆
时间尺度 当前任务、在线、临时 跨任务、离线、持久
容量 有限，易溢出 近乎无限，但检索受限
内容 当前目标、对话、工具输出、计划、草稿 过去的具体事件：任务、行动、结果、失败、反思
功能 推理、决策、执行、控制注意力 积累经验、跨任务迁移、避免重复犯错
智能体映射 上下文窗口、状态板、草稿本 向量库、日志、知识图谱、经验池

2. 动态关系：编码与检索的循环

· 情景记忆 → 工作记忆：检索
  当前任务开始时，智能体根据目标、线索、相似性，从情景记忆中检索相关经历，加载到工作记忆。比如：“上次类似任务用某工具失败了，这次换一个。”
· 工作记忆 → 情景记忆：编码
  当前任务结束后，工作记忆中的轨迹、评估结果、反思被压缩、抽象后写入情景记忆。不是全存，而是存关键教训、策略、失败模式。
· 反思是桥梁
  在反思架构中：
  工作记忆中的失败轨迹 → Evaluator 评估 → Self-Reflection 生成反思 → 写入情景记忆 → 下次检索回工作记忆
  这就是 Reflexion 等框架的核心闭环。

3. 相互塑造

· 工作记忆中的记忆目标与线索决定“从情景记忆里取什么”。
· 检索到的情景记忆又改变工作记忆中的计划、假设和行动策略。
· 工作容量有限，所以情景记忆不能直接全塞进去，必须经过相关性过滤、摘要、优先级排序。
· 情景记忆若被污染或过时，会误导工作记忆；工作记忆若不做反思和巩固，情景记忆就得不到更新。

4. 常见误区

· 把上下文窗口直接等同于工作记忆：它只是工作记忆的主要载体之一，还缺执行控制和目标管理。
· 把工作记忆当情景记忆：对话一关就丢，无法跨任务学习。
· 把情景记忆全量塞回工作记忆：上下文爆炸，检索噪声淹没关键信息。
· 只存成功不存失败：失去反思架构最重要的学习信号。

5. 一句话总结

工作记忆是“此刻正在处理什么”，情景记忆是“过去发生过什么、学到了什么”。
工作记忆是情景记忆的读写缓存，情景记忆是工作记忆的经验后备；反思则是两者之间的写入与检索机制。
