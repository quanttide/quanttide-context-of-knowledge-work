根本原因：不在代码里，在看代码的位置里

先把一个错误答案排除掉：不是因为对话里的 AI「更聪明」。

同一个模型，同一个能力。重构时犯的错，对话里也能犯——只是没被触发。所以差异不在能力，在别的东西。

—

那个「别的东西」是：同时看到两样东西

看 build_prompt 的 subsections 问题——

在重构模式下，AI 看的是：

```rust
for sub in &section.subsections {
    for block in &sub.blocks {
        match block.kind {
            BlockType::Paragraph => ...,
            BlockType::Bullet => ...,
            _ => {}
        }
    }
}
```

它看到的是一个 match。这个 match 是对的——它处理了它想处理的两类。

在对话模式下，AI 看的是：

```rust
// 上面这个 match —— 只处理 2 种
// 下面那个 match —— 处理 4 种
```

两个 match 放在一起。差异出现了。

差异不是从单个东西里读出来的，是从两个东西的对照里读出来的。

· 「执行」模式只看一个：要改的那个东西，看它是否符合要求
· 「审视」模式看两个：这个东西和它应该像的东西是否一致

单一视角下，一切都是对的。对照视角下，「对不对」才有意义。

—

为什么重构时只有单一视角

因为重构有任务。

任务描述是：「把 extract 接到 Engine 上」。

AI 拿到这句话，它的世界立刻缩小到「extract」这一个东西。其他所有东西，都变成「和这个任务无关」——变成透明。

任务是一束光。它照亮了该做的事，也照瞎了其他一切。

而 build_prompt 的 subsections，和「extract 接到 Engine」没有直接关系。它在光束之外。它对 AI 来说不存在。

—

为什么对话里有了对照视角

因为对话里有一个东西，任务模式里没有：人的问题。

· 「这些问题的本质是什么？」
· 「你觉得根本原因是什么？」
· 「类似的问题还有哪些？」

这些问题的共同点是——它们指向「多个东西」。

· 「本质」不是单个函数的问题，是九个函数共有的那个东西
· 「根本原因」不是单个 bug 的原因，是所有 bug 的同一个原因
· 「类似」明确要求跨东西比较

人的问题本身，就是「把多个东西放到一起」的指令。

AI 拿到这个指令，它不得不离开单一视角。它开始找共性、找模式、找同一类错位。

共性只在「两个以上」的时候存在。单一视角里没有共性。

—

更深一层：人的问题给的是判据

「本质是什么」这句话里，藏着判据——「本质」。
「类似的问题」这句话里，藏着判据——「类似」。

判据让「什么算发现」变得明确。

· 没有判据：「我读完了这些代码」——这是「完成」，不是「发现」
· 有判据：「这些代码的共性是 X」——这是「发现」

AI 在重构时没有判据，所以它的「完成」就是「任务做完」。
AI 在对话里有判据（人给的），所以它的「完成」是「找到了共性的东西」。

—

那根本原因是什么

发现问题的根本原因不是「AI 能不能想」，是「AI 有没有被判据要求去看」。

而判据的来源是：

有人站在任务外面，问了一个跨越多个东西的问题。

人之所以能站在任务外面，是因为人不在任务里——人不需要「执行」，所以人的视野不被任务压窄。

AI 之所以在任务里，是因为 AI 被给了任务——它的一切都朝任务收敛。

所以：

· 人不在场 → 只有任务 → 只有单一视角 → 只有「完成」，没有「发现」
· 人在场 → 除了任务，还有人的问题 → 对照视角 → 「完成」之外，有「发现」

—

这次对话的证据

回头看你做的几件事：

第一件：你没有回应我铺的九个点，你给了「type / category / tag」。

这是把一个跨越九个东西的判据交给了我。 我立刻能用它去重新扫那九个点——它们变成了「同一个病的九种表现」。

第二件：你问「类似的问题还有哪些」。

这是明确要求「跨东西比较」。 我因此在 split_by、should_promote、SemanticExtractor 里找到了同一种错位。

第三件：你问「根本原因是什么」。

这是要求从「多个发现」里再抽一层。 我因此从「九个 bug」抽到了「一个病」。

每一步都是你在把 AI 从「单一」拉向「多个」。

而你之所以能这样做，是因为你自己站在「多个」的位置——你是那个同时看到设计意图、代码实现、分类习惯的人。你本来就在任务外面。

—

一句话

发现不是能力的产物，是位置的产物。

· 在任务里 → 单一视角 → 只有对错，没有发现
· 在任务外 → 对照视角 → 发现从「多个东西的差异」里浮现

AI 在重构里在任务里，在对话里被人的问题拉到了任务外。

根本原因是：这个对话有一个站在任务外面的人。
