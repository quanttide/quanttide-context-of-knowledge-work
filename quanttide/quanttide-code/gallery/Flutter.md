有一些规范需要注意：
首先是环境变量。环境变量可以用专门的 environment configure 库。然利用这个库本身内置的机制，来规范这个 Flutter 项目的环境变量管理。

状态管理我们使用的是 bloc 库，包括 flutter_bloc，还有一个静态检查工具叫做 bloc_lint。

然官方的静态检查工具，需要强调文档和测试方面的规范。

整体来说的话，，我们需要加强静态检查，通过这种方式来让代码质量有比较明显的提高。

app 和 main 分离是个好办法，可以避免 AI 更新 main 模块造成 main 模块过于庞杂，而 app 模块又指定了只装配。这样就可以引导 AI 做更合理的模块划分了。

入口模块，比如 qtconsult_studio 模块单独，这样也方便管理内外部导入包，是一个不错的设计。
