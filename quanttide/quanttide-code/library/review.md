## ASD-STE100

ASD-STE100（Simplified Technical English，简化技术英语）是一套国际标准化的受控自然语言，旨在让技术文档的表述更清晰、一致，易于全球不同母语背景的读者理解，并降低翻译成本。

📜 起源与背景

它起源于20世纪80年代，最初是为解决航空业维护手册因写作风格各异而造成的理解难题。该标准最初由欧洲航空航天工业协会（AECMA）开发，当时称为“AECMA简化英语”，后由航空航天与国防工业协会（ASD） 接管并维护，现已广泛应用于航空航天、国防、制造等多个行业。

🏗️ 核心结构：两大组成部分

ASD-STE100标准由第一部分：写作规则和第二部分：受控词典构成。

第一部分：写作规则
涵盖语法和文风，核心原则包括：

· 使用主动语态，明确动作执行者。
· 每句只表达一个指令，避免复杂长句。
· 限制句子长度：程序性文本（如操作步骤）句子不超过20个单词；描述性文本不超过25个单词。
· 限制名词簇：连续名词组合不超过3个单词。

第二部分：受控词典
提供约900个经过筛选的“批准词”，每个词通常只对应一个含义和一种词性，以消除歧义。

· 同义词唯一化：例如，只用 start，不用 begin、commence 或 initiate。
· 词性固定：例如，test 仅被批准作名词使用，不能作动词。
· 技术术语扩展：允许在规则下使用公司或项目特定的“技术名词”和“技术动词”。
